# IoT 수업 프로젝트

두원공과대학교 메카트로닉스공학과 마지막 학기(2024년 2학기) IoT 수업 과제입니다.

## 스마트폰 앱으로 커튼과 방문을 여닫는 장치

- 구성: 스마트폰 앱(MIT App Inventor)에서 블루투스로 명령을 보내면, ESP32 기반 보드(i2r-03)의 릴레이 두 개로 DC 기어모터를 제어합니다. 모터 축에 끼우는 부품만 바꿔서, 하나의 장치로 방문(바퀴 부품)을 여닫고 커튼(커튼 부품)을 올리고 내릴 수 있게 했습니다.
- 코드: ESP32에 올리는 코드는 Arduino C++로 직접 작성했습니다. 블루투스 시리얼로 받은 명령(up, down, stop)을 해석해 릴레이 두 개를 켜고 꺼서 모터의 회전 방향과 정지를 제어합니다.
- 제작: 앱의 화면과 블록 코드, 보드와 릴레이와 모터의 회로 연결을 구성했습니다. 커튼 바퀴만 Thingiverse의 부품을 가져와 Tinkercad로 편집했고, 나머지 부품은 Creo로 직접 모델링했습니다. 모두 집에서 3D 프린터로 출력해 제작했습니다.
- 소스: [Daa-e/IoT](https://github.com/Daa-e/IoT)

## IoT-PLC 기기를 서버와 연동해 제어

수업에서 제공된 i2r IoT-PLC 기기(ESP32 기반 보드)를 Node-RED, AWS EC2, MQTT와 연동해 핸드폰과 웹에서 모니터링하고 제어하는 과제를 단계별로 진행했습니다. 온습도 측정과 표시, 출력 시간과 스케줄 설정, 입력 on/off 설정, 두 대 이상의 보드 구동, MQTT로 LED 스위치 제어를 했습니다. 보드와 라이브러리, 실습 자료는 수업에서 제공된 것을 사용했습니다.
