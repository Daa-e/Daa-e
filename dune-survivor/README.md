# Dune Survivor

모래 언덕 유적에서 몰려오는 적을 상대하는 1인칭 생존 로그라이트 게임입니다. 적을 처치해 능력치를 강화하고 보스를 공략합니다.

| | |
|---|---|
| 기간 | 2026.05 |
| 팀 | 6인 |
| 환경 | UE5 · C++ |
| 담당 | 캐릭터 스킬과 RPG 투사체 · 포탈 기반 스테이지 진행 · 캐릭터 스탯, 이동, 대시 |

팀 저장소는 비공개입니다.

## RPG 투사체 범위 피해 스킬 시스템

- 목표: RPG 스킬 하나로 여러 적을 공격하되, 스킬 교체와 쿨타임, 범위 피해를 나눠 다루고 싶었습니다. 같은 적이 여러 컴포넌트로 잡혀도 피해는 한 번이어야 했습니다.
- 설계: 쿨타임을 가진 스킬 베이스 클래스를 상속한 스킬이 투사체를 스폰하고 피해, 반경, 타격 횟수를 넘깁니다. 폭발 시 `SphereOverlapActors` 결과를 TSet으로 걸러 `ApplyDamage`를 호출합니다.
- 결과: 성공한 스킬에만 쿨타임이 걸리고, 같은 적에게는 한 번만 피해가 들어갑니다.

## 무기 교체 구조 단순화

- 목표: 무기 획득과 교체가 WeaponBox와 PlayerCharacter 두 곳에 나뉘어 장착 코드가 복잡했습니다. 교체 뒤에도 무기별 탄약은 유지돼야 했습니다.
- 설계: WeaponBox 의존 로직을 걷어내고 총기 스왑 방식으로 되돌렸습니다. 팀원이 만든 탄약 보존 구조(SavedAmmoMap)는 그대로 살렸습니다.
- 결과: PlayerCharacter.cpp 1,034줄에서 878줄, WeaponBox.cpp 131줄에서 56줄, WeaponBox 분기문 7개에서 0개가 됐습니다. 세 파일 합계 20% 감소했습니다.

## 방 클리어 포탈과 랜덤 스테이지 진행

- 목표: Level_1~5를 무작위 순서로 돌고, 정해진 스테이지 수가 지나면 보스 맵으로 가야 했습니다. 맵이 바뀌어도 진행 상태가 남아야 했습니다.
- 설계: 포탈은 처음에 닫혀 있다가 조건이 채워지면 열립니다. 진입하면 GameInstance의 레벨 목록을 Fisher-Yates로 한 번 섞고, 방문한 레벨은 지우며, 정해 둔 횟수를 넘으면 보스 맵으로 이동합니다. 포탈을 여는 조건은 팀원의 스포너가 호출합니다.
- 결과: 다섯 레벨이 중복 없이 무작위로 이어지고 보스로 마무리됩니다. 보스 이후에는 진행 상태를 초기화합니다.

## RPG 장착 중 일반 총 발사 차단

- 문제: RPG를 든 상태에서도 일반 총이 발사되고, 총과 손이 함께 보였습니다. 발사 입력의 진입 지점에 RPG 장착 확인이 없었습니다.
- 해결: 발사 함수 첫 줄에서 RPG 장착 중이면 바로 return합니다. RPG를 들 때 총을 멈추고 숨기며, 실제로 쓰는 기본 Mesh를 숨기고, 해제할 때 복구합니다.
- 결과: RPG를 쓰는 동안 일반 총이 나가지 않고, 해제하면 원래대로 돌아옵니다. 기존 발사 로직은 건드리지 않았습니다.
