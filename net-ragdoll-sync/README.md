# Net Ragdoll Sync

CrossWalk에서 겪은 래그돌 위치 문제를 일반화한 UE 5.8용 C++ 플러그인입니다. 개인 프로젝트이며 2026년 10월 21일 Fab에 출시해 판매 중입니다.

[Fab 상품 페이지](https://www.fab.com/listings/fc5a7521-68bd-434c-a187-2d41fb1c000c)

플러그인 소스는 판매 상품이라 이 저장소에 포함하지 않았습니다.

## 구성

`NetRagdollComponent` 하나를 Character에 붙이고 서버에서 `StartRagdoll`을 호출합니다. 서버가 루트 본을 초당 약 20회 보내고, 클라이언트는 실제 도착 간격으로 보간합니다.

## 검증

동기화 켜기와 끄기, 지연과 손실 세 조건을 자동으로 돌려 로그로 비교했습니다.

- 측정 지표: 일어서는 순간의 수평 위치 튐(cm)
- 조건: 리슨 서버, 조건당 래그돌 10건
- 지연 없는 조건에서 20.2cm이던 튐이 1.9cm로 줄었습니다.
- 프레임이 다른 별도 프로세스에서도 동기화 쪽은 2cm대로 같은 경향이었습니다.
- 래그돌 도중 접속한 클라이언트도 1.0cm 차이로 복구됐습니다.
- 비행 중 궤적은 로컬 물리보다 정확하지 않고 약 50~60ms 늦게 따라갑니다. 맞춰 주는 것은 최종 위치와 기립 위치입니다.

## 한계

루트 본 하나만 동기화하고 Character만 지원하며, 리슨 서버에서만 검증했습니다.

## 개발 방식

개발에는 Claude Code를 활용했고, 측정과 검증은 직접 진행했습니다. Fab 상품 페이지에도 AI 사용 여부를 표시했습니다.
